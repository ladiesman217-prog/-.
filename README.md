# Генератор тем курсовых и дипломных проектов

Учебный проект для студентов Западно-Казахстанского аграрно-технического университета имени Жангир хана. Пользователь выбирает образовательную программу, тип работы, курс и пройденные дисциплины. Генератор предлагает темы с целью, задачами и ожидаемым результатом.

Список программ взят со [страницы направлений подготовки университета](https://wkatu.edu.kz/ru/napravleniya-podgotovki/). Примерные предметы в каталоге — подсказки, а не официальный учебный план. Студент может добавить свои темы.

## Веб-приложение

1. Установи Python 3.10 или новее.
2. Запусти `start.bat`.
3. Открой `http://127.0.0.1:5000`.

## Запуск через Docker

Нужен Docker Desktop с включённым Docker Compose. В PowerShell из папки проекта выполни:

```powershell
docker compose up --build -d
docker compose ps
docker compose logs api
```

Открой `http://localhost:5000`. API-контейнер подключается к PostgreSQL-контейнеру по имени `db` во внутренней сети Compose. Проверить API и базу можно запросом `http://localhost:5000/api/health`. После генерации запись сохраняется в таблице `generations`.

Остановить, снова запустить и полностью завершить контейнеры:

```powershell
docker compose stop
docker compose start
docker compose down
```

Для просмотра сохранённых записей выполни `docker compose exec db psql -U topics_user -d topics -c "SELECT id, major, level, language, created_at FROM generations ORDER BY id DESC LIMIT 10;"`.

На форме можно выбрать язык ответа (русский или казахский) и количество идей (3, 5 или 8). Word-файл `.docx` размером до 6 МБ можно загрузить в блоке материалов: его текст будет добавлен к темам для генерации. В Telegram-боте доступны те же настройки, а Word-файл можно отправить боту сообщением.

После выбора специальности форма сразу предлагает указать, нужна курсовая или дипломная работа. Затем можно выбрать примеры предметов и добавить собственные.

## Telegram-бот

Бот использует тот же каталог специальностей и те же функции генерации, что и веб-приложение.

1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot` и следуй его инструкциям.
2. Открой файл `.env` в папке проекта на рабочем столе и вставь выданный токен после `TELEGRAM_BOT_TOKEN=`. Сам токен никому не отправляй и не публикуй.
3. Запусти `start_bot.bat`. Он подготовит Python-окружение, установит нужные библиотеки и запустит бота. Окно консоли должно оставаться открытым, пока бот работает.
4. Найди своего бота по имени пользователя, которое указал у BotFather, и отправь `/start`.

В боте пользователь последовательно выбирает специальность, тип работы, курс и предметы. Можно отметить предложенные предметы и дописать собственные.

## ИИ и ключи

Для Gemini API создай ключ в Google AI Studio, добавь его в `GEMINI_API_KEY` в `.env` и оставь `AI_PROVIDER=gemini`. По умолчанию выбран `gemini-3.6-flash`. После изменения `.env` перезапусти приложение или бота. Gemini предлагает бесплатный тариф с ограничениями; на бесплатном тарифе содержимое запросов может использоваться для улучшения продуктов Google, поэтому не загружай конфиденциальные материалы.

Можно также выбрать `AI_PROVIDER=openai` и указать `OPENAI_API_KEY`, либо установить `AI_PROVIDER=auto`, чтобы автоматически использовать Gemini при наличии его ключа, иначе OpenAI. Храни ключи только в `.env`, не вставляй их в HTML, JavaScript, Telegram или публичный репозиторий. Без настроенного ключа приложение выдаёт демонстрационные примеры.

`OPENAI_MODEL` задаёт модель (по умолчанию `gpt-4.1-mini`). Для ответа Telegram-бота нужен токен от BotFather в `TELEGRAM_BOT_TOKEN`.

## Структура

- `app.py` — Flask-сервер и общая функция генерации тем.
- `telegram_bot.py` — Telegram-бот с выбором специальности, типа работы, курса и предметов.
- `static/catalog.json` — общий каталог программ и примерных дисциплин.
- `static/index.html`, `static/style.css`, `static/app.js` — веб-интерфейс.
- `requirements.txt` — Python-зависимости.
