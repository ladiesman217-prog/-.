# Практическая работа №4

## Что находится в папке

- исходный код веб-клиента, REST API и Telegram-бота;
- `Dockerfile` для образа API;
- `docker-compose.yml` для API и PostgreSQL;
- `requirements.txt` со списком Python-зависимостей;
- `README.md` с установкой, запуском и командами проверки;
- этот краткий отчёт и инструкция по отправке.

Личный файл `.env` и API-ключи в пакет не включены. Для настройки есть безопасный шаблон `.env.example`.

## Что показать преподавателю

1. Откройте `README.md` и раздел «Запуск через Docker».
2. В PowerShell из папки проекта выполните:

```powershell
docker compose up --build -d
docker compose ps
Invoke-RestMethod http://localhost:5000/api/health
```

3. Покажите запрос клиента к API:

```powershell
$body = @{ major='Агрономия'; studied='Почвоведение'; level='course'; year='2'; language='ru'; count=3 } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://localhost:5000/api/generate -ContentType 'application/json; charset=utf-8' -Body $body
```

4. Проверьте логи, перезапуск и запись в PostgreSQL командами из README.

## Как загрузить на GitHub

1. Войдите в GitHub и создайте новый репозиторий.
2. Откройте репозиторий, выберите **Add file → Upload files**.
3. Перетащите содержимое папки проекта или распакуйте ZIP и загрузите файлы.
4. Нажмите **Commit changes**.

Не загружайте `.env`, пароли, Telegram-токен или API-ключи. Если GitHub просит добавить секрет из `.env`, отмените загрузку и удалите этот файл из списка.

## Архитектура

```text
Клиент (браузер) → Flask REST API (контейнер api) → PostgreSQL (контейнер db)
```

Контейнеры запускаются через Compose и связаны внутренней сетью. API обращается к базе по имени `db`; результаты сохраняются в таблицу `generations`.

## Результат

Подготовлен проект, который можно запустить в Docker, проверить через HTTP-клиент и передать на GitHub. В интерфейсе доступны русский и казахский языки, выбор количества вариантов (3, 5 или 8) и загрузка учебных материалов в формате `.docx`.
